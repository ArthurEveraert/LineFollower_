# Elektronische tekeningen

[easyeda_linefollower_planB.json](easyeda_linefollower_planB.json) is een EasyEDA-project met het schema "plan B" van de robot.

Het schema bevat onder andere:
- de DRV8833 motor driver module (zie [H-brug proof of concept](../../code/proof%20of%20concepts/hbridge/readme.md))
- de 18650-batterijhouders (2S)
- een LED

Het bestand is een export van EasyEDA. Open het in EasyEDA om het schema te bekijken of aan te passen.

Dit schema is niet volledig: de Arduino Nano ESP32, de IR-sensoren en de zekeringhouder staan niet in het bestand. Aansluitingen daarvan staan in de [finaal readme](../../code/finaal/readme.md).
