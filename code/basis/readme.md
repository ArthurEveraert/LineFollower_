# basis programma

volgende zaken werken samen in dit template project  

* instelbare parameters mbv. SerialCommands 
  * cyclus tijd
  * debug on/off
  * start/stop
* parameters worden opgeslagen in eeprom geheugen
* start/stop kan ook geactiveerd worden mbv. een externe interrupt
* draadloze communicatie

Met behulp van de cyclus kan je bvb. een knipperende led programmeren.

## status

Het basisprogramma als apart template staat nog niet in deze map. De uitwerking van de lijnvolger staat in [finaal](../finaal/readme.md): de parameters en kalibratie worden daar via een WiFi-webpagina ingesteld in plaats van via SerialCommands.

De sensor-test uit het oorspronkelijke basisbestand staat nu in [proof of concepts/sensor](../proof%20of%20concepts/sensor/readme.md).
